# EducaPlay Primaria · prototipo

Prototipo navegable de la plataforma Educaplay Primaria (Descubrir, Proyectar y
Acompañar), con el sistema visual de Kapi y arte flat correntino.

- **Ver en línea:** https://educaplay-primaria-prototipo.netlify.app
- **Ver en la computadora:** abrir `index.html`. No necesita servidor ni conexión.

La documentación completa (arte, animación, herramientas y pendientes) está en `LEEME.md`.
